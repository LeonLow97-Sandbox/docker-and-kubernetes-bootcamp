# CKAD Scenario 1: Multi-container Pods & Shared Volumes

## **Context**

A developer needs to deploy a pod where a sidecar container generates data that the main application container serves.

## **Task**

Create a Pod named `busybox-logger` in the default namespace.

## **Requirements**

- **Main container**
  - Name: `web-container`
  - Image: `nginx`
  - Mount path: `/usr/share/nginx/html`
- **Sidecar container**
  - Name: `sidecar-container`
  - Image: `busybox`
  - Command: `/bin/sh`, `-c`, `while true; do date >> /var/log/index.html; sleep 5; done`
  - Mount path: `/var/log`
- **Storage**
  - Use an `emptyDir` volume named `shared-data` so both containers can access the same `index.html` file.
- Ensure the `sidecar-container` writes to the same file that `nginx` serves.

## **Validation**

Once the pod is running, verify that the command below returns a list of dates generated by the sidecar:

```sh
kubectl exec busybox-logger -c web-container -- curl localhost
```
